# TrendDetector — сканер зарождения тренда (Binance-only)

Радар режима рынка. Смотрит три вещи, предшествующие движению:

1. **VPIN / токсичность ленты** — кто давит в aggTrade (buy vs sell за 1ч и 4ч).
2. **OBI и его скорость** — намерение стакана (растёт ли перекос, куда).
3. **Ширина рынка** — сколько монет давят в одну сторону по OBI-правилу.

Правило:
- **trend_fuel** — токсичность + OBI + цена пошла в ту же сторону.
- **accumulation** — токсичность есть, цены нет (кто-то тихо набирает).
- **ignition** — токсичность + OBI + ширина + рост токсичности + контекст (ливка),
  но цена ещё не убежала.
- **breadth diff ≥ 40 п.п.** — «рынок поехал».

Ничего не пишется на диск. Всё живёт в памяти и показывается в дашборде.

## Запуск

    poetry install --no-root
    poetry run python selfcheck.py
    poetry run python main.py
